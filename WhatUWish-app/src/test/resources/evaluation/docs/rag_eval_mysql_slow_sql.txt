标题：MySQL 慢 SQL 排查要点

一、日志与指标
慢 SQL 排查通常先看 slow query log、QPS、TPS、活跃连接数、锁等待时间和 buffer pool 命中率。

二、执行计划
对目标 SQL 需要查看执行计划，关注是否走索引、是否出现全表扫描、回表过多、临时表、filesort，以及多表 join 顺序是否合理。

三、排查顺序
先确认是单条 SQL 突然变慢，还是整体数据库压力升高。再看 SQL 模板、绑定参数分布和近期是否有数据量变化。之后用 explain 或 explain analyze 判断索引选择是否异常，并结合业务侧调用频次评估影响范围。

四、常见原因
常见根因包括缺失索引、联合索引顺序不合理、大分页、统计信息不准、热点更新导致锁竞争，以及 SQL 改写后失去索引条件。
