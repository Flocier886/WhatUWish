标题：CPU 飙高时用 Arthas 定位热点线程

一、场景定义
当 Java 进程 CPU 持续升高时，常见目标不是立刻修改代码，而是先快速定位最忙线程，再判断属于死循环、频繁重试、锁竞争还是大量对象处理。

二、关键命令
Arthas 常用命令是 `thread -n 3`，用于查看当前最忙的几个线程。拿到线程 id 后，可以继续查看线程栈，结合 `stack`、`trace` 或 jstack 分析热点调用路径。

三、排查步骤
第一步，先确认是单个进程还是系统整体 CPU 异常。第二步，进入目标 JVM，执行 `thread -n 3`。第三步，记录最忙线程 id 与线程名。第四步，对热点线程做栈分析，判断是否存在循环计算、频繁日志打印或异常重试。第五步，再结合 GC、接口流量和业务变更时间做交叉验证。

四、判断要点
如果多个线程都高 CPU，可能是流量放大或线程池任务堆积；如果只有少数线程持续占用，通常更像局部热点逻辑或锁争用。
